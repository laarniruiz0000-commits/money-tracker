Money Tracker V3 PWA v2.2 Web Test

Major changes:
- Salary Cutoff View merged into Payday View.
- Payday 10th covers the 10th-24th; Payday 25th covers the 25th-9th of the next month.
- Payday calculation subtracts actual expenses and unpaid bills/installments in the window.
- Expenses form Type now has Expense, Bill, Installment, Budget.
- Category no longer contains Bills, Budget, or Installment.
- Budget can be added from Expenses and is planning-only; it does not reduce Current Money.
- Bills Overview can filter Bill vs Installment and by bank.
- Search & Transaction History has Edit/Delete for salary, expenses, bills/installments, and budgets.
- Installments accept starting # OR start month. If only # is given, the transaction date month is used.
- Installment editing supports amount, description, bank, starting #, total, start month, and due day; paid historical installment bills remain unchanged.
- Bills added in Expenses are stored in the Bills Overview automatically.
- Cache version bumped to v2.2.
